# CampusBites

CampusBites is a web project that helps students discover and share food options on campus. It is built with HTML, CSS and JavaScript and runs in any modern web browser.

## Getting Started

Clone the repository from GitHub, open the project folder, and open the main HTML file in your browser.

## Branches

- **main**: the stable, working version
- **partner-work**: partner contributions, merged into main through a pull request

## Contributing

Pull the latest changes before you start, work on your own branch, write clear commit messages, and open a pull request for review.
